# AI Usage Report

## 1. Overview

AI tools were used as an assistance resource during the Quality Engineer assessment to support Playwright automation, TypeScript understanding, test execution, troubleshooting, performance testing, and documentation.

## 2. AI Assistance in Playwright Automation

AI tools assisted with the following activities:

- Understanding the Playwright project structure and automation workflow.
- Explaining TypeScript syntax, test scripts, assertions, fixtures, and page object models.
- Understanding existing test scenarios and automation logic.
- Providing guidance on executing Playwright tests and interpreting test results.
- Troubleshooting errors and explaining validation output.
- Understanding test organization and automation best practices.
- Assisting with Git commands, version control, and GitHub submission.

## 3. Validation Performed

The following checks were completed during assessment preparation:

- TypeScript validation completed successfully.
- The recorded Playwright test run completed with one test passing.
- Test output was reviewed to understand the execution result.

These results represent the recorded test run and do not guarantee that every possible scenario has been validated.

## 4. AI Assistance in Performance Testing

AI tools provided guidance on configuring and executing a basic Apache JMeter performance test against the OrangeHRM demo login page.

The test configuration used:
- Virtual users: 5
- Ramp-up period: 10 seconds
- Loop count: 3
- Total requests: 15

### Recorded Results

| Metric | Result |
|---|---:|
| Average response time | 951 ms |
| Minimum response time | 327 ms |
| Maximum response time | 3,834 ms |
| Error rate | 0% |
| Throughput | Approximately 1.1 requests/second |

The test covered a single HTTP GET request to the login page. It was a small-scale test and does not establish production capacity or high-concurrency performance.

## 5. Documentation and Troubleshooting

AI tools also assisted with:
- Preparing technical documentation.
- Explaining performance test metrics.
- Troubleshooting Git commands and GitHub operations.
- Organizing assessment artifacts for submission.

## 6. Limitations

AI-generated suggestions were used as guidance and may require human review or adaptation. The reported validation results apply only to the specific test runs performed. This report does not claim that every AI suggestion or every part of the project was independently verified.
